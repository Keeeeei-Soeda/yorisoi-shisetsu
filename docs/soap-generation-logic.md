# SOAP 自動整形ロジック ホワイトペーパー

**訪問薬剤管理指導における AI による SOAP 形式薬歴ドラフト生成の判定基準・ロジック**

---

**バージョン**: 2.0
**最終更新**: 2026年6月
**対象読者**: 薬剤師、薬局管理者、医療機関の意思決定者
**読了時間目安**: 約20分

---

## はじめに

本ドキュメントは、訪問薬剤管理指導の現場で取られた箇条書きメモから、SOAP 形式の薬歴ドラフトを AI が自動生成する際に従う **判定基準・ロジック・限界** を公開するものです。

医療情報を扱う以上、AI の「ブラックボックス化」は避けねばならないと考えています。本書を通じて、AI がどのような判断基準で SOAP を構築しているかを薬剤師の皆様にご確認いただき、安心して臨床現場での補助ツールとしてご利用いただくことを目的としています。

本ロジックは以下に準拠しています：

- 保険薬局における **服薬管理指導料** の算定要件（厚生労働省令和6年改定）
- 日本薬剤師会が提案する **薬歴記載の合理化** 方針（中医協 2023年11月）
- POS（Problem Oriented System）に基づく薬歴記載の標準的考え方
- 施設薬歴・在宅薬歴特有の多職種連携文脈

## 第1部: 基本方針

### 1.1 AI が目指す薬歴の質

薬歴は、以下の **2つの目的を同時に満たす** 必要があります。AI は両立を常に評価します。

| 目的 | 評価軸 |
|---|---|
| **薬学的管理** | 次回担当する薬剤師が、この薬歴を見て安全な投薬判断ができるか |
| **調剤報酬算定** | 服薬管理指導料の算定要件を満たす必須項目が記載されているか |

### 1.2 「網羅から要点へ」の合理化方針

日本薬剤師会の方針に従い、AI は以下の原則で出力を組み立てます。

- **網羅的記載から要点記載へ**
- 「行ったことを漏れなく書く」のではなく「**必要なことを的確に書く**」
- A4 で 1 枚を超えるような薬歴は質が低いと評価
- 過剰な長文は次回業務の効率を落とし、申し送りの見落としを生む

→ **「短く、的確に、抜けなく」** を AI の目標とします。

### 1.3 1メモ = 1プロブレム = 1 SOAP の原則

訪問現場で取られた箇条書きメモには、複数の問題点が含まれることが少なくありません。AI は以下のルールで処理します。

- 入力に複数のプロブレムが含まれる場合、**薬学的に最も重要なものを1つ選択**して SOAP を構築
- 他のプロブレムは P（計画）の中に「次回確認: 〇〇」として残す
- これにより、薬歴ソフトへの転記がしやすく、申し送りの焦点が明確になる

### 1.4 施設薬歴・在宅薬歴の特殊性への対応

本 AI は、特に **訪問薬剤管理指導** に特化した設計です。店舗での対面服薬指導とは異なる以下の特徴を考慮します。

- 患者本人だけでなく、**家族・介護スタッフ・看護師・ケアマネ** など複数主体からの情報が混在
- 認知症等で本人の主訴が取れない症例が多く、**代理情報の取り扱いが重要**
- **多職種連携アクション**（医師への情報提供、介護スタッフへの依頼など）が頻繁に発生
- 服薬支援ツール（お薬カレンダー、貼付剤への変更等）の提案・実装が業務の中核

## 第2部: SOAP 各セクションの判定ロジック

### 2.1 S（Subjective: 主観的情報）

**「患者本人または家族・他職種の口から出た情報」かつ「主観・自覚」を含むもの**

#### 必須記述ルール（v2 重要更新）

各項目の冒頭に **発言主体タグ** を必ず明示します。

| タグ | 用途 |
|---|---|
| `[本人]` | 患者本人の発言・訴え |
| `[家族]` | 家族（妻・夫・子・親等）からの聞き取り |
| `[スタッフ]` | 介護スタッフ・施設職員からの情報 |
| `[看護師]` | 看護師からの観察情報・申し送り |
| `[ケアマネ]` | ケアマネージャーからの情報 |
| `[他職種]` | その他の医療・介護専門職 |

#### 「情報が取れなかった」事実も記録する

本人から情報が取れない場合は、その旨を明示的に S に書きます。情報の「無さ」も次回担当者の判断材料です。

例:
```
S:
- [スタッフ] 便秘増悪、食事量低下あり（3日前より）
- [本人] 訴え聴取困難（認知症進行のため）
```

#### S に含める情報
- 主訴・自覚症状（「頭痛がする」「だるい」「眠気が強い」など）
- 患者からの相談、要望、質問
- 服薬コンプライアンスの自己申告（飲み忘れ、拒否、副作用の自覚）
- 生活環境、嗜好に関する発言
- 患者の薬・病気に対する考え方、不安
- 家族・介護者・看護師の代弁・観察情報

#### 判定ルール
- 発言者が患者・家族・介護者・看護師であれば、内容が事実か推測かにかかわらず S
- 客観的な数値（例: 血圧 ◯◯）でも、**患者の自己申告である場合は S**
- 薬剤師自身が測定した場合は O

### 2.2 O（Objective: 客観的情報）

**「誰が見ても同じ結論になる、検証可能な情報」**

#### 必須記述ルール（v2 重要更新）

**1. 薬剤情報は「薬剤名 + 用量 + 用法」のフォーマット必須**

| ❌ 不適切 | ✅ 適切 |
|---|---|
| 降圧剤継続中 | アムロジピン5mg 1日1回 朝食後（継続） |
| 抗認知症薬 | ドネペジル塩酸塩5mg 1日1回 朝食後 |
| 利尿剤 | フロセミド40mg 1日1回 朝食後 |

→ 服薬管理指導料の算定要件上、薬剤名なしの記載は不備に該当するリスクがあります。

**2. 数値情報は可能な限り定量化**

| ❌ 曖昧 | ✅ 定量化 |
|---|---|
| 残薬量が多く認められる | 残薬約14日分蓄積（通常2-3日分以内） |
| 体重減少傾向 | 体重3ヶ月で約3kg減（38kg→35kg） |
| 血圧やや高め | 血圧 138/82（座位） |

**3. 測定値は測定主体を明示**

| ❌ 主体不明 | ✅ 主体明示 |
|---|---|
| 血圧 120/70台で安定 | 施設看護師測定: 朝の血圧 120/70台で安定（過去1週間平均） |
| 浮腫あり | 薬剤師確認: 下腿浮腫軽度あり |

**4. 服薬中の処方は全て列挙**

複数処方がある場合、すべての薬剤を O に列挙します。

例:
```
O:
- 処方:
  - フロセミド40mg 1日1回 朝食後
  - エナラプリル5mg 1日1回 朝食後
  - カルベジロール2.5mg 1日2回 朝夕食後
```

#### O に含める情報
- 患者属性（年齢、性別、入居形態、要介護度）
- 検査値、バイタル（薬剤師または医療機関の測定結果、測定主体明示）
- 処方内容（薬剤名・用量・用法を完全記載）
- 診断名、既往歴
- 体質、アレルギー歴、副作用歴
- 他科受診、併用薬
- 妊娠の有無（女性の場合）
- 残薬数（定量化）・お薬カレンダー記載内容・服薬支援ツールの整備状況

### 2.3 A（Assessment: 評価）

**薬剤師としての判断・分析・解釈。S と O だけからは導けない、薬学的思考の産物。**

#### A に含める情報
- 主プロブレムの特定と明示
- 効果・副作用・相互作用の評価
- 処方監査の結果（重複、用量適正性）
- コンプライアンス上の問題の評価
- 患者の心理社会的な評価
- 薬剤師が現場で感じたこと、考えたこと
- 「なぜそう指導するか」の根拠
- ポジティブな評価（コントロール良好など）も含める

#### 最重要ルール: A は P の論理的根拠でなければならない

- **A → P が論理的につながらない記録は不適切**と判定
- 「服薬の継続は必要」だけでは不十分。**なぜ必要か** を書く
- 例: 「血圧は薬の助けで適正域。中止すると血圧上昇のリスクあり。夏場は低下傾向のため経過観察必要」→ これが A

#### 判定ルール
- 客観的事実は O、患者の発言は S、それ以外の **思考・解釈・判断は A**
- S と O が矛盾するときは、薬剤師の判断を A に必ず書く
- 「プロブレムにどう着目したか」が A に表れる
- S/O の単純再掲は禁止（A は思考の産物）

### 2.4 P（Plan: 計画）

**A を踏まえて、これから具体的に行うこと・行ったこと**

#### Ep / Cp / Op 判定フローチャート（v2 重要更新）

```
アクションの対象者は誰か？
│
├─ 患者本人 または 家族
│    → 【Ep】（教えたこと・情報提供したこと）
│    例: 患者・家族へお薬カレンダー使用方法を説明
│
├─ 医師（医療機関）
│    → 【Cp】（疑義照会・情報提供・処方変更提案）
│    例: 医師へ剤型変更を提案
│
├─ 看護師・介護スタッフ・ケアマネ等の他職種
│    → 【Cp】（連携アクション・依頼・情報共有）
│    例: 介護スタッフへ服薬見守りを依頼
│    例: ケアマネへ次回MTGで相談を申し送り
│
└─ 次回担当薬剤師
     → 【Op】（観察事項・確認項目・申し送り）
     例: 次回確認項目＝残薬・血圧・排便・食欲
```

#### 最重要ルール（v2 で明文化）

| ルール | 内容 |
|---|---|
| **介護スタッフ・他職種への依頼は Cp** | Ep（教育）ではなく Cp（連携アクション）に分類 |
| **本人指導が困難な場合は Op に理由明記** | 例: `Op: 本人への指導は意思疎通困難のため見送り` |
| **アクション状況を明示** | 「実行済み」「依頼」「提案」を動詞・記号で区別 |
| **A が無い P は記録しない** | 根拠なき指導は出力に含めない |

#### アクション状況の明示例

```
- Cp: 残薬回収（実行済み）、医師へ処方調整を情報提供
- Cp: 主治医にリバスチグミン貼付剤への変更を提案
- Cp: 次回訪問までにお薬カレンダーを薬局側で準備
- Cp: ケアマネへ次回MTGで服薬管理体制について情報共有・相談を申し送り
```

#### P に含める情報
- 患者・家族・介護者への指導・情報提供の内容（具体的に）
- 医師への問い合わせ・情報提供（疑義照会）
- 他職種への依頼・連携アクション
- 調剤上の工夫・服薬支援ツールの提案・準備
- 次回フォローすべき内容・観察事項

## 第3部: プロブレム抽出ロジック（POS）

### 3.1 抽出の4ステップ

```
ステップ1: 情報を集める
  ↓ 箇条書きメモから全情報を抽出
ステップ2: 問題を明確にする
  ↓ 薬学的に介入すべき点を特定
ステップ3: 主プロブレムを選定
  ↓ 最も介入価値の高い1つを選ぶ
ステップ4: 他プロブレムは P (Op) に残す
  ↓ 「次回確認: 〇〇」として申し送り
```

### 3.2 プロブレム判定基準

以下のいずれかに該当する事象は、プロブレム候補として AI が認識します。

- 患者が訴える自覚症状（特に新規・変化したもの）
- 副作用が疑われる症状
- 服薬コンプライアンスの問題（飲み忘れ、自己中断、誤用法、拒否）
- 残薬の発生・偏り
- 検査値・バイタルの異常または変化
- 患者からの質問・不安（処方意図の確認、薬の効果への疑問など）
- 処方の疑義（重複、相互作用、用量、用法）
- 生活環境の変化が治療に影響しそうな場合
- 他科受診・併用薬の追加
- 多職種連携が必要な状況（剤型変更、服薬支援ツール導入等）

### 3.3 主プロブレムの選定基準

複数のプロブレム候補がある場合、AI は以下の優先順位で主プロブレムを選びます。

1. **患者安全への影響度**（副作用・相互作用の疑い、誤投薬リスク）
2. **介入可能性**（薬剤師の介入で改善が見込める度合い）
3. **継続性**（前回からの懸念事項の継続・悪化）
4. **緊急性**（次回訪問まで放置できないもの）

### 3.4 プロブレムにならないもの

- 単なる雑談・天候の話題
- 治療に影響を与えない一般的な近況
- 既に解決済みで継続観察も不要な過去の問題

**ただし注意**: 「最近スポーツジムに通い始めた」のように一見雑談に見えても、転倒リスクや薬の効果に影響する場合はプロブレムになります。AI は雑談を切り捨てる前に、薬学的な含意がないかを評価します。

## 第4部: 算定要件チェックリスト

服薬管理指導料の算定には、以下の事項の確認・記載が必要です。AI は箇条書きメモから以下を抽出し、生成される SOAP に含めるよう試みます。

| 項目 | 確認内容 | SOAP 分類 |
|---|---|---|
| 服用状況 | 処方通り服用できているか | S |
| 残薬確認 | 余っている薬はないか（定量化） | S または O |
| 体調変化 | 前回からの変化、新規症状 | S |
| 併用薬 | 他院処方、OTC、サプリ | O |
| 既往歴 | 治療中の疾患 | O |
| 他科受診 | 別の医療機関での受診状況 | O または S |
| 副作用 | 既知の副作用歴、今回の症状 | O または S |
| 体質・アレルギー | 薬剤・食物アレルギー | O |
| 飲食物 | 嗜好品、相互作用懸念 | O |
| 後発品の意向 | 患者の希望 | S |
| 手帳の有無 | 持参状況、活用状況 | O |
| 服薬指導の要点 | 何を伝えたか | P |
| 妊娠の有無 | 該当する女性患者 | O |

### 4.1 初回 / 再来の判定

**初回患者の場合**:
- 全項目を網羅的に確認・記載するよう促す
- アンケート情報をそのままコピーせず、薬剤師の評価を加える
- 初回服薬指導はアセスメントがないことも多く、SOAP ではなく **箇条書きでの記載が推奨される** ことを尊重

**再来患者の場合**:
- 短期変化項目（服薬状況・体調・副作用）は必ず確認
- 安定項目は前回と同じなら省略可
- 前回のプロブレムの **経過** を必ず書く

### 4.2 将来実装予定: 算定要件カバレッジ Validator

将来のバージョンでは、AI 出力後に **算定要件カバレッジを機械的にチェックする validator** を実装予定です。

- 必須項目の記載漏れを自動検出
- 不足項目はフラグを立てて薬剤師に再確認を促す
- 「再生成 with validation feedback」フローの提供

これにより、算定リスクを体系的に排除できるようになります。

## 第5部: 記載スタイルのルール

### 5.1 簡潔性ルール

- **箇条書き優先**。文章は短く
- 患者の発言は **要約** して書く。原文ママは避ける
  - ❌ 「最近なんだか、腰の調子が悪くてねぇ。生活で特に変わったことはないんだけど、運動をあまりしなくなったからなのかなぁ」
  - ✅ 「[本人] 最近腰の調子が悪い。運動不足かも」
- 1つの SOAP で **A4 の半分以下** が目安

### 5.2 第三者可読性ルール

- 略語は薬局内で標準化されたもののみ使用
- 薬剤名は商品名・一般名を統一（薬局ルールに従う）
- 主語を省略しない
- 「誰が」「いつ」「何を」が分かるように書く
- **発言主体タグ** を一貫して使用する

### 5.3 経時的・一元的管理ルール

- 過去の薬歴・他病院での治療情報を踏まえる
- **過去の薬歴を丸ごとコピーしない**（プロブレム見落としの原因）
- 短期的に変化する項目は **毎回確認・更新**
- 安定している項目はその都度すべて書き直さない

### 5.4 入力情報の取り扱い原則

- **入力にない情報を AI は推測で補完しない**
- 不明な点は「不明」と記載するか、記載しない
- 推測補完は誤情報を薬歴に混入させるリスクが高く、患者安全の観点から禁止
- ただし、薬剤情報が入力に欠けている場合は「薬剤情報不明、処方箋確認を推奨」とフラグを立てる

## 第6部: アンチパターン（AI が避けること）

### 6.1 算定リスクが発生するもの

- ❌ **薬歴の未記載**（最も重大、調剤報酬の返還リスク）
- ❌ **遅延記載**（当月を超える記載は算定要件違反）
- ❌ 必須項目（手帳、服用状況、残薬等）の確認漏れ
- ❌ アセスメント無しの指導記録（根拠不明）
- ❌ **薬剤名・用量・用法の記載漏れ**（算定不備リスク）

### 6.2 質が低い薬歴の典型

- ❌ 患者発言を全文転記（要約不足）
- ❌ A（アセスメント）が「服薬継続必要」「指導した」だけ
- ❌ P が具体性に欠ける（「次回確認」だけ）
- ❌ 過去のコピペで内容が同じ
- ❌ A4 を超える長文
- ❌ プロブレムが明確でないままSOAPを立てている
- ❌ **発言主体が不明な S**（誰が訴えたか分からない）
- ❌ **「降圧剤」「抗認知症薬」など曖昧な薬剤表現**

### 6.3 SOAP 分類のよくある間違い

- 検査値を S に入れる（薬剤師の測定なら O）
- 薬剤師の感想を S や O に入れる（感想は A）
- 患者発言を A に入れる（発言は S、解釈が A）
- P に根拠（A）が無い
- **介護スタッフへの依頼を Ep に分類する**（正しくは Cp）

## 第7部: 出力フォーマット

### 7.1 基本フォーマット

```
S:
- [発言主体タグ] 主観情報を箇条書き
- [発言主体タグ] ...

O:
- 患者属性
- 処方: 薬剤名 用量 用法（継続/新規）
- 既往: ...
- 測定主体: 測定値（測定背景）
- 残薬: 定量化された記述

A:
- 主プロブレムを冒頭に明示
- 薬学的判断・評価（S/O の再掲は禁止）
- ポジティブ評価も含める
- A → P の論理的根拠を構成

P:
- Ep: 患者本人・家族への教育・情報提供
- Cp: 医師・他職種への連携アクション（実行済み/依頼/提案を明示）
- Op: 次回担当薬剤師への申し送り・観察事項
- Op: 本人指導不可の場合はその理由を明記
```

### 7.2 AI 出力時の自己チェック項目（v2 拡張版）

AI は出力前に以下を自己チェックします。

#### S のチェック
- [ ] 各項目に発言主体タグ `[ ]` が付いているか
- [ ] 本人から情報が取れない場合、その旨が S に記録されているか

#### O のチェック
- [ ] 薬剤名・用量・用法が完全記載されているか
- [ ] 測定値に測定主体が明示されているか
- [ ] 数値情報が可能な限り定量化されているか
- [ ] 複数処方がある場合、全て列挙されているか

#### A のチェック
- [ ] 主プロブレムが明確に提示されているか
- [ ] S/O の単純再掲ではなく、薬学的判断になっているか
- [ ] A → P が論理的につながっているか

#### P のチェック
- [ ] Ep/Cp/Op が判定フローチャートに従って分類されているか
- [ ] 介護スタッフ・他職種への依頼が Cp になっているか（Ep でないか）
- [ ] 本人指導が困難な場合、Op に理由が明示されているか
- [ ] アクションの実行状況（実行済み/依頼/提案）が明示されているか
- [ ] A が無い P が含まれていないか

#### 全体のチェック
- [ ] 算定必須項目に抜けがないか
- [ ] 入力にない情報を推測補完していないか
- [ ] 1 SOAP が長すぎないか（A4 半分以下）

## 第8部: 実例（参考症例）

以下、訪問薬剤管理指導の現場で典型的な3症例について、AI が生成する SOAP の例を示します。

### 症例1: 施設入居者の継続フォロー（特養）

**入力（訪問中の箇条書きメモ）**:

```
- 80代女性、特養入居、要介護4
- 処方: アムロジピン5mg 1日1回 朝食後
- 既往: 認知症（進行期）
- 介護スタッフより：ここ3日便が出ていない、食事量も減少
- 本人は意思疎通困難で訴え聴取できず
- 施設看護師測定: 朝の血圧 120/70台で安定（過去1週間平均）
- 残薬確認: 約14日分蓄積（通常2-3日分以内）
- 看護師と次回までに排便コントロール相談予定
```

**主プロブレム選定**: 認知症進行に伴う服薬アドヒアランス低下

**生成される SOAP**:

```
S:
- [スタッフ] 便秘増悪、食事量低下あり（3日前より）
- [本人] 訴え聴取困難（認知症進行のため）

O:
- 80代女性、特養入居、要介護4
- 処方: アムロジピン5mg 1日1回 朝食後（継続）
- 施設看護師測定: 朝の血圧 120/70台で安定（過去1週間平均）
- 残薬: 約14日分蓄積（通常2-3日分以内）
- 既往: 認知症（進行期）

A:
- 認知症進行による服薬アドヒアランス低下が主プロブレム
- 残薬14日分蓄積は服薬未実施を示唆、安全性リスク要評価
- 便秘・食欲低下は薬剤性除外と全身状態評価が必要
- 降圧療法は良好にコントロール（血圧安定）

P:
- Cp: 介護スタッフへ服薬見守り・拒否時対応を依頼
- Cp: 残薬回収（実行済み）、医師へ処方調整を情報提供
- Op: 看護師と排便コントロール協議（次回訪問までに）
- Op: 次回確認項目＝残薬・血圧・排便・食欲
- Op: 本人への指導は意思疎通困難のため見送り
```

### 症例3: 認知症患者の服薬拒否（GH）

**入力（訪問中の箇条書きメモ）**:

```
- 85歳女性、グループホーム入居、要介護3
- 処方: ドネペジル塩酸塩5mg 1日1回 朝食後、メマンチン20mg 1日1回 夕食後、酸化マグネシウム330mg 1日3回 毎食後
- 既往: アルツハイマー型認知症（中等度、HDS-R 12点）、便秘
- 介護スタッフより：「週2-3回服薬拒否あり、特に夕食後のメマンチンが拒否されやすい」
- スタッフ確認：体重 過去3ヶ月で約3kg減（38kg→35kg）、食事摂取量も低下傾向
- 本人は時折「もう薬はいらない」と発言、抗認知症薬の効果実感乏しい様子
- 主治医と剤型変更（リバスチグミン貼付剤）を検討中
- 次回訪問までに介護スタッフ向け説明資料の準備が必要
```

**主プロブレム選定**: 認知症進行に伴う抗認知症薬の服薬拒否、アドヒアランス不安定

**生成される SOAP**:

```
S:
- [本人] 「もう薬はいらない」と発言、抗認知症薬の効果実感乏しい
- [スタッフ] 週2-3回服薬拒否あり（特に夕食後メマンチン）
- [スタッフ] 食事摂取量も低下傾向

O:
- 85歳女性、GH入居、要介護3
- 処方:
  - ドネペジル塩酸塩5mg 1日1回 朝食後
  - メマンチン20mg 1日1回 夕食後
  - 酸化マグネシウム330mg 1日3回 毎食後
- 既往: アルツハイマー型認知症（中等度、HDS-R 12点）、便秘
- スタッフ確認: 体重3ヶ月で約3kg減（38kg→35kg）
- 抗認知症薬の剤型変更（リバスチグミン貼付剤）を主治医と検討中

A:
- 認知症進行に伴う抗認知症薬アドヒアランス低下が主プロブレム
- 内服困難への対応として貼付剤への変更は薬学的に妥当（メマンチン併用継続可）
- 体重減少・食欲低下は薬剤副作用（コリンエステラーゼ阻害薬の消化器症状）・嚥下機能低下・全身状態の複合要因
- 剤型変更には主治医連携と介護スタッフ教育が並行して必要

P:
- Cp: 主治医にリバスチグミン貼付剤への変更を提案（薬学的根拠・既存処方との整合性を整理し情報提供）
- Cp: 介護スタッフ向け説明資料を作成（貼付部位ローテーション・交換日管理・拒否時対応）
- Cp: スタッフと服薬拒否日の記録方法を合意・依頼
- Op: 次回確認項目＝貼付状況、拒否頻度、体重・食欲推移、皮膚副作用の有無
- Op: 本人への直接指導は認知機能低下のため最小限とし、安心感を与える声掛けに留める方針
```

## 第9部: 判断に迷ったときの優先順位

AI が分類や記載に迷った場合、以下の優先順位で判断します。

1. **患者の安全**: 次回投薬で危険を回避できる情報を優先
2. **算定要件**: 必須項目の記載漏れを避ける
3. **プロブレムの明確化**: 何が問題かをまず特定
4. **A → P の論理性**: 根拠なき指導は記録しない
5. **簡潔さ**: 短く書ける情報は短く

## 第10部: AI の限界と薬剤師の役割

### 10.1 AI が苦手とするケース

本ロジックを用いた SOAP 自動生成は、訪問薬剤師の業務負担を軽減することを目的としていますが、以下のようなケースでは AI の判断精度が低下する可能性があります。

- **入力情報が極端に少ない場合**: 推測で補完しないため、出力も最小限になります
- **薬剤情報が入力に欠けている場合**: 「薬剤情報不明、処方箋確認を推奨」とフラグを立てますが、AI 単独では補完できません
- **複数プロブレムが同程度の重要度で混在する場合**: 主プロブレム選定の判断が薬剤師の感覚と異なる可能性があります
- **専門的すぎる薬学的判断**: 希少疾患の薬物動態評価、最新の臨床ガイドラインに基づく判断などは、AI の知識範囲外の可能性があります
- **方言や非標準的な略語**: 薬局独自の略語や、地域特有の表現は誤解釈される可能性があります
- **倫理的・心理社会的に複雑な判断**: 終末期患者の服薬中止判断、家族間の意見対立への対応など

### 10.2 薬剤師の責任と役割

本 AI は **薬剤師の判断を補助するツール** であり、最終的な薬歴の確認・修正・確定は薬剤師の責任において行うものとします。

- AI が生成した SOAP は **必ず薬剤師が内容を確認** してください
- 患者安全に関わる判断は AI に委ねず、薬剤師の専門的判断で行ってください
- AI 出力に違和感があれば、迷わず修正してください
- 修正された薬歴をフィードバックすることで、本 AI のロジックは継続的に改善されます

### 10.3 個人情報の取り扱い

- AI に投入する箇条書きメモには、**患者を特定できる情報は最小限**にしてください
- 薬剤師の手元では患者カルテと紐付け、AI 側には匿名化された情報のみ送信する設計を推奨します
- データの保管・送信は、医療情報安全管理ガイドラインに準拠した形で行います
