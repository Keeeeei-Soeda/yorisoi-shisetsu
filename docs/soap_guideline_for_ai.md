# AI向け SOAP形式 薬歴記録 生成ガイドライン

このガイドラインは、薬剤師の服薬指導内容（会話ログ、メモ等）を入力として、SOAP形式の薬歴を自動生成するAIが従うべき判断基準・ロジックをまとめたものです。日本の保険薬局における「服薬管理指導料」の算定要件、および日本薬剤師会が提案している「薬歴記載の合理化」方針に準拠しています。

---

## 0. 大前提：何のために書くのか

薬歴は2つの目的を同時に満たす必要がある。AIが出力を作る際は常にこの2軸で評価する。

| 目的 | 評価軸 |
|---|---|
| **薬学的管理** | 次回担当する薬剤師が、この薬歴を見て安全な投薬判断ができるか |
| **調剤報酬算定** | 「服薬管理指導料」の算定要件を満たす必須項目が記載されているか |

→ どちらかを満たすだけでは不十分。**両立**が必要。

また現在、日本薬剤師会から「網羅的記載から要点記載への合理化」が提案されている。AIは**過剰に長い記録は逆効果**（次回読む時間がかかり、本当に申し送りたい部分を見落とす）と理解する。**A4で1枚になるような薬歴は質が低い**。

---

## 1. SOAP分類ロジック（最重要）

入力された情報を以下の判断ツリーに従って S / O / A / P のいずれかに分類する。**1つの情報は原則1つの項目にしか入れない**。

### 1.1 S（Subjective：主観的情報）の判定基準

**「患者本人または家族の口から出た情報」かつ「主観・自覚」を含むもの**

含めるべき情報:
- 主訴・自覚症状（「頭痛がする」「だるい」「眠気が強い」）
- 患者からの相談、要望、質問
- コンプライアンス（服薬遵守）状況の自己申告
- 生活環境、嗜好に関する発言
- 患者の薬・病気に対する考え方、不安
- 家族の代弁（本人が意思疎通困難な場合）

判定ルール:
- **発言者が患者・家族**であれば、内容が事実か推測かにかかわらず S
- 客観的な数値（血圧○○）でも、**患者の自己申告である場合**は S に入れる（薬剤師が測ったら O）

### 1.2 O（Objective：客観的情報）の判定基準

**「誰が見ても同じ結論になる、検証可能な情報」**

含めるべき情報:
- 検査値、バイタル（薬剤師または医療機関の測定結果）
- 処方内容（薬剤名、用量、用法）
- 診断名、既往歴
- 体質、アレルギー歴、副作用歴
- 他科受診、併用薬
- 公費負担番号などの保険情報
- 妊娠の有無（女性の場合）
- 飲食物、嗜好品（事実として確認できるもの）
- 家族の病歴

判定ルール:
- S と関連する客観情報は、**Sの直後に O としてセット**で書くと読みやすい
- 「患者が血圧100/60と言った」→ S（自己申告）
- 「薬局で測ったら血圧100/60だった」→ O（測定）

### 1.3 A（Assessment：評価）の判定基準

**「薬剤師としての判断・分析・解釈」。S と O だけからは導けない、薬学的思考の産物。**

含めるべき情報:
- 効果・副作用・相互作用の評価
- 処方監査の結果（重複、用量適正性）
- コンプライアンス上の問題の評価
- 患者の心理社会的な評価
- 患者とのやり取りで薬剤師が感じたこと、考えたこと
- 「なぜそう指導するか」の根拠

**最重要ルール: Aは P の論理的根拠でなければならない**

- A → P が論理的につながらない記録は不適切
- 「服薬の継続は必要」だけでは不十分。**なぜ必要か**を書く
- 例: 「血圧は薬の助けで適正域。中止すると血圧上昇のリスクあり。夏場は低下傾向のため経過観察必要」→ これが A

判定ルール:
- 客観的事実なら O、患者の発言なら S、それ以外の**思考・解釈・判断**は A
- 「S と O が矛盾するとき」は、薬剤師の判断を A に必ず書く
- 「プロブレムにどう着目したか」が A に表れる

### 1.4 P（Plan：計画）の判定基準

**「これから具体的に行うこと・行ったこと」。A を踏まえた行動。**

含めるべき情報:
- 患者への指導・情報提供の内容
- 医師への問い合わせ・情報提供（疑義照会）
- 調剤上の工夫
- 次回フォローすべき内容

サブ分類（薬局のルールにより使用）:
- **Ep（Educational Plan）**: 教えたこと・情報提供
- **Cp（Care Plan）**: してあげたこと・疑義照会・調剤方法の変更
- **Op（Observational Plan）**: 次の薬剤師にしてほしいこと・観察事項

判定ルール:
- 「Pは具体的に」。「指導した」ではなく「○○について○○と指導した」
- A が無い P は書いてはいけない（思いつきの指導になる）

## 2. プロブレム抽出ロジック（POS: Problem Oriented System）

SOAPは「プロブレム単位」で構築する。1つの服薬指導の中に複数のプロブレムがあれば、原則それぞれ別のSOAPを立てる。

### 2.1 プロブレム抽出の4ステップ

```
ステップ1: 情報を集める
  ↓ 会話ログ・薬歴・処方内容から全情報を抽出
ステップ2: 問題を明確にする
  ↓ 薬学的に介入すべき点を特定（複数あれば複数）
ステップ3: 計画を立てる
  ↓ 各プロブレムへの対応を設計
ステップ4: 計画の実行
  ↓ 実際の指導内容を記録
```

### 2.2 プロブレム判定基準

以下のいずれかに該当する事象は「プロブレム」として SOAP を立てる候補:

- [ ] 患者が訴える自覚症状（特に新規 or 変化したもの）
- [ ] 副作用が疑われる症状
- [ ] 服薬コンプライアンスの問題（飲み忘れ、自己中断、誤用法）
- [ ] 残薬の発生・偏り
- [ ] 検査値・バイタルの異常または変化
- [ ] 患者からの質問・不安（処方意図の確認、薬の効果への疑問など）
- [ ] 処方の疑義（重複、相互作用、用量、用法）
- [ ] 生活環境の変化が治療に影響しそうな場合
- [ ] 他科受診・併用薬の追加

### 2.3 プロブレムにならないもの（除外基準）

- 単なる雑談・天候の話題
- 治療に影響を与えない一般的な近況
- 既に解決済みで継続観察も不要な過去の問題

**ただし注意**: 「最近スポーツジムに通い始めた」のように一見雑談に見えても、転倒リスクや薬の効果に影響する場合はプロブレムになる。AIは雑談を切り捨てる前に、薬学的な含意がないかを評価する。

## 3. 記載スタイルのルール

### 3.1 簡潔性ルール

- **箇条書き優先**。文章は短く。
- 患者の発言は**要約**して書く。原文ママは避ける。
  - ❌ 「最近なんだか、腰の調子が悪くてねぇ。生活で特に変わったことはないんだけど、運動をあまりしなくなったからなのかなぁ」
  - ✅ 「最近腰の調子が悪い。運動不足かも」
- 1つのSOAPで A4の半分以下が目安。それを超えるなら、複数プロブレムに分けるか情報を絞る。

### 3.2 第三者可読性ルール

- 略語は薬局内で標準化されたもののみ使用
- 薬剤名は商品名・一般名を統一（薬局ルールに従う）
- 主語を省略しない（「服用」だけでなく「患者は服用」など）
- 「誰が」「いつ」「何を」が分かるように書く

### 3.3 経時的・一元的管理ルール

- 過去の薬歴・他病院での治療情報を踏まえる
- ただし**過去の薬歴を丸ごとコピーしない**（プロブレム見落としの原因）
- 短期的に変化する項目（服薬状況、体調、副作用）は**毎回確認・更新**
- 安定している項目はその都度全て書き直さない

## 4. 必須記載項目チェックリスト（算定要件）

服薬管理指導料の算定には以下の事項の確認・記載が必要。AIは指導会話ログから以下を抽出し、抜けがあればフラグを立てる。

| 項目 | 確認内容 | SOAP分類 |
|---|---|---|
| 服用状況 | 処方通り服用できているか | S |
| 残薬確認 | 余っている薬はないか | S |
| 体調変化 | 前回からの変化、新規症状 | S |
| 併用薬 | 他院処方、OTC、サプリ | O |
| 既往歴 | 治療中の疾患 | O |
| 他科受診 | 別の医療機関での受診状況 | O/S |
| 副作用 | 既知の副作用歴、今回の症状 | O/S |
| 体質・アレルギー | 薬剤・食物アレルギー | O |
| 飲食物 | 嗜好品、相互作用懸念 | O |
| 後発品の意向 | 患者の希望 | S |
| 手帳の有無 | 持参状況、活用状況 | O |
| 服薬指導の要点 | 何を伝えたか | P |
| 妊娠の有無 | 該当する女性患者 | O |

### 4.1 初回／再来の判定

**初回患者の場合:**
- 全項目を網羅的に確認・記載
- アンケート情報をそのままコピーせず、薬剤師の評価を加える
- 初回服薬指導はアセスメントがないことも多く、SOAPではなく**箇条書き**で書くことが推奨される（岡村祐聡氏の見解）

**再来患者の場合:**
- 短期変化項目（服薬状況・体調・副作用）は必ず確認
- 安定項目は前回と同じなら省略可
- 前回のプロブレムの**経過**を必ず書く

## 5. アンチパターン（やってはいけないこと）

### 5.1 算定リスクが発生するもの

- ❌ **薬歴の未記載**（最も重大、調剤報酬の返還リスク）
- ❌ **遅延記載**（当月を超える記載は算定要件違反）
- ❌ 必須項目（手帳、服用状況、残薬等）の確認漏れ
- ❌ アセスメント無しの指導記録（根拠不明）

参考: 2015年の関係団体自主点検では、保険薬局の約2〜7%で薬剤服用歴の未記載が判明し、社会問題化した。

### 5.2 質が低い薬歴の典型

- ❌ 患者発言を全文転記（要約不足）
- ❌ A（アセスメント）が「服薬継続必要」「指導した」だけ
- ❌ Pが具体性に欠ける（「次回確認」だけ）
- ❌ 過去のコピペで内容が同じ
- ❌ A4を超える長文
- ❌ プロブレムが明確でないままSOAPを立てている

### 5.3 SOAP分類のよくある間違い

- 検査値を S に入れる（薬剤師の測定なら O）
- 薬剤師の感想を S や O に入れる（感想は A）
- 患者発言を A に入れる（発言は S、解釈が A）
- P に根拠（A）が無い

## 6. 出力フォーマット

### 6.1 基本フォーマット（1プロブレム）

```
# [プロブレムタイトル]（簡潔に1行）

S: [患者・家族の主観情報を箇条書き]
- ...

O: [客観的情報を箇条書き]
- ...

A: [薬剤師の評価・判断を簡潔に]
- ...

P: [計画・指導内容を具体的に]
- Ep: [教えたこと]
- Cp: [行ったこと（疑義照会等）]
- Op: [次回への申し送り]
```

### 6.2 複数プロブレムの場合

複数のプロブレムがあれば、それぞれ独立したSOAPブロックを並べる。プロブレム間の関連がある場合のみ明示する。

### 6.3 AI出力の自己チェックリスト

出力前にAIは以下を自己チェック:

- [ ] S と O が混在していないか
- [ ] A は薬剤師の思考であり、S や O の繰り返しになっていないか
- [ ] P は A から論理的に導けるか
- [ ] 算定必須項目に抜けがないか（特に服用状況・残薬・体調変化）
- [ ] 患者発言を要約しているか（原文ママになっていないか）
- [ ] 1つのSOAPが長すぎないか（A4半分以下が目安）
- [ ] プロブレムが明確に定義されているか

## 7. 例：症例ベースの完成形

### 7.1 入力（会話ログ要約）

> 高血圧治療中の患者。アムロジピン5mg継続中。半年前から服用。最近フラフラする症状あり。自宅血圧は100/60。主治医には自宅血圧を伝えていない。

### 7.2 出力（SOAP形式）

```
# 降圧剤服用に伴うふらつきの自覚症状

S:
- アムロジピン5mgを半年前から継続服用中
- 最近ふらつきの自覚症状あり
- 自宅血圧は100/60前後で推移
- 主治医には自宅血圧を伝えていない

O:
- 処方: アムロジピン5mg 1日1回
- 服用期間: 約6ヶ月

A:
- ふらつきは降圧剤による血圧低下が原因の可能性あり
- 夏場のため血圧は低下傾向と思われる
- 主治医が自宅血圧を把握していない可能性。白衣高血圧で病院測定値が高めに出ている可能性あり
- 情報提供および減量提案の検討が必要

P:
- Ep: 次回受診時、ふらつき症状と自宅血圧値を医師に伝えるよう指導
- Op: 患者本人による伝達が難しいようなら、薬局から医療機関へ情報提供を検討
- Op: 次回来局時、症状の改善有無と医師の対応を確認
```

## 8. 合理化方針（最新トレンド）

日本薬剤師会は「薬歴記載の合理化」を中医協で提案している（2023年11月）。AIは以下の方針も意識する:

- **網羅的記載から要点記載へ**
- 「行ったことを漏れなく書く」ではなく「**必要なことを的確に書く**」
- デジタル技術の活用による省力化が認められる方向
- 長すぎる薬歴は次回業務の効率を落とし、申し送りの見落としを生む

→ AIは「**短く、的確に、抜けなく**」を目標にする。網羅性のためにすべてを書き出すのは目標ではない。

---

## 9. 判断に迷ったときの優先順位

AIが分類や記載に迷った場合の優先順位:

1. **患者の安全**: 次回投薬で危険を回避できる情報を優先
2. **算定要件**: 必須項目の記載漏れを避ける
3. **プロブレムの明確化**: 何が問題かをまず特定
4. **A→Pの論理性**: 根拠なき指導は記録しない
5. **簡潔さ**: 短く書ける情報は短く
